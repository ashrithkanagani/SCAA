# SCAA: Selective Causal Auditing for Agentic Systems

All 4 phases complete: severity-gated selective explanation for sequential agent decisions, validated across **four domains** (one synthetic + two more synthetic + one on real published benchmark data), with a cross-domain audit dashboard.

**Start here:** `reports/RUN_AND_TEST_GUIDE.md` (setup + to-do checklist), then `reports/FINAL_RESEARCH_REPORT.md` (paper-writing reference with citations).

## Quick start

```bash
pip install -r requirements.txt
python3 -m pytest tests/ -v          # 64 tests, ~4s
python3 -m scaa.reproduce            # everything automatic, all 4 domains, ~20-30s
open dashboard/index.html            # then load dashboard/dashboard_data.json
```

## The four domains

| Domain | Environment | Agent | Data |
|---|---|---|---|
| Industrial/IoT scheduling | `scaa/environment.py` | `ScoringAgent` / `GreedyEDFAgent` | Synthetic |
| Delivery/logistics dispatch | `scaa/domains/delivery/` | `NearestWindowAgent` | Synthetic |
| Cloud/datacenter scheduling | `scaa/domains/cloud/` | `SLAAwareAgent` | Synthetic |
| Job-shop scheduling | `scaa/domains/taillard/` | `SPTDispatchAgent` | **Real** Taillard (1993) / Lawrence (1984) benchmark instances |

Every domain calls the **exact same, unmodified** `scaa/severity.py` functions — proven by a regression test (`tests/test_domains.py`), not just claimed.

## Project layout

```
scaa/
  config.py, environment.py, agent.py, trace.py, simulate.py    - Domain 1 core (Phase 1)
  attribution.py, severity.py, narration.py                      - THE gate + attribution + narration
  baselines.py, scenarios.py, evaluation.py, human_study.py      - Phase 3 evaluation infra
  pipeline.py, reproduce.py, visualize.py                        - orchestration
  domains/                                                        - Phase 4: cross-domain
    common.py                - shared simulation/attribution/calibration loop
    cross_domain_evaluation.py - multi-domain metrics
    dashboard_data.py          - aggregates dashboard/dashboard_data.json
    delivery/, cloud/, taillard/  - one environment+agent+narrator per domain
dashboard/
  index.html                 - single-file cross-domain audit console (no build step)
data/taillard/                - real Taillard/Lawrence benchmark instance files
tests/                         - 64 unit tests across 8 files
outputs/                       - JSON + figure artifacts (regenerated by scaa.reproduce)
reports/                       - all documentation (see index above)
```
