# SCAA: Selective Causal Auditing for Agentic Systems

All 3 phases complete. **Start here:** `reports/RUN_AND_TEST_GUIDE.md` (setup + to-do checklist), then `reports/FINAL_RESEARCH_REPORT.md` (everything needed to write the paper, with citations).

## Quick start

```bash
pip install -r requirements.txt
python3 -m pytest tests/ -v          # 44 tests, ~3s
python3 -m scaa.reproduce            # everything automatic, ~9s
```

## Project layout

```
scaa/
  config.py       - all tunable parameters
  environment.py  - deterministic discrete-event industrial/IoT scheduling simulator
  agent.py        - ScoringAgent (primary) + GreedyEDFAgent (cross-agent validation)
  trace.py        - DecisionStep / Trajectory data schema
  simulate.py     - shared run loop (real + counterfactual runs)
  attribution.py  - drop/hold-out counterfactual influence scoring
  severity.py     - THE NOVEL MODULE: irreversibility + impact + deviation -> gate
  narration.py    - deliberately simple narration layer (template + optional Groq)
  baselines.py    - 5 selection strategies compared in the evaluation
  scenarios.py    - 3 named scenarios (balanced, high_contention, safety_critical)
  evaluation.py   - Phase 3: multi-seed metrics, significance tests, ablation, cross-agent
  human_study.py  - human-study template generation + scoring
  visualize.py    - matplotlib figures for the paper/presentation
  pipeline.py     - single-run orchestration
  reproduce.py    - single-command full reproduction
tests/            - 44 unit tests across 7 files
outputs/          - JSON + figure artifacts (regenerated by scaa.reproduce)
reports/          - all documentation (see index above)
```
